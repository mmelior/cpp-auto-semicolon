# Плагин: Auto Semicolon for C++

**Автор:** Охота Степан Сергеевич, Группа: 561000_M3114

## Описание
Это расширение для Visual Studio Code, созданное для ускорения написания кода на C++. 
Плагин позволяет автоматически расставлять точки с запятой (`;`) в конце выделенных строк кода.

## Возможности
- Быстрое добавление `;` в конец каждой непустой строки в выделенном фрагменте.
- Умная проверка: если точка с запятой уже стоит, плагин не будет добавлять вторую.
- Работает через контекстное меню (правая кнопка мыши) при выделении текста.

## Как использовать
1. Напишите несколько строк кода на C++ без точек с запятой.
2. Выделите нужные строки мышкой.
3. Нажмите правую кнопку мыши и выберите **"Add Semicolons to Selection"**.
4. Все строки закончатся на `;`.
